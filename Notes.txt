Install and run

# 1. Create and activate a virtual environment (Python ≥ 3.11)
python -m venv .venv
.venv\Scripts\activate          # Windows PowerShell
# source .venv/bin/activate     # macOS / Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure your API key
copy .env.example .env          # Windows
# cp .env.example .env          # macOS / Linux
# Edit .env — set ANTHROPIC_API_KEY (or OPENAI_API_KEY) and MODEL

# 4. Run
python main.py
Outputs: discrepancy_report.txt (human-readable) and discrepancy_report.json (structured), plus live agent reasoning on the console.

What the three agents do
Agent	Tool	Output model
Contract Data Extractor	read_contract_pdf	ContractTerms
Invoice Data Extractor	read_invoice_pdf	InvoiceData
Discrepancy Analyst	(none — uses task context)	DiscrepancyReport
Data flows via context=[contract_task, invoice_task] on the analyst task — no manual string passing.

Known discrepancies the system will flag
From reading the actual PDFs:

Item	Contract price	Invoice price	Gap
Homepage wireframe & revisions	$210.00	$220.00	+$10.00 overcharge
Product photo retouching package	$150.00	$145.00	-$5.00 undercharge
Monthly hosting setup	$65.00	$60.00	-$5.00 undercharge
Website design consultation	$85.00/unit	2 × $85.00	qty flag (contract doesn't restrict to 1)
Subtotal net difference	—	—	$0.00 (the three errors cancel out)
Payment terms / method / tax / totals	—	—	all correct
Assumptions made
Quantity on consultation: The contract says "$85.00 per unit" without an explicit quantity cap, so billing 2 units is structurally allowed — the analyst will note it but not necessarily hard-flag it.
Tax rate: The contract says "applicable sales tax shall be added" without specifying a rate; 8.25% on the invoice is treated as the buyer's jurisdiction rate, so no discrepancy there unless the analyst deems the rate unverifiable.
CrewAI version: Tested against the crewai>=0.80 API (output_pydantic on Task, LLM(model=...), @tool from crewai.tools). If you hit import errors on an older install, run pip install --upgrade crewai.

To run with Gemini:

Copy .env.example → .env
Set your Gemini API key (get one free at aistudio.google.com):

GEMINI_API_KEY=your_key_here
MODEL=gemini/gemini-2.0-flash
Install the updated dependencies:

pip install -r requirements.txt
Run:

python main.py
CrewAI routes Gemini calls through LiteLLM using the gemini/ model prefix, so no extra configuration is needed beyond the API key.
